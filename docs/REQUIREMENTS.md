# 需求文档：0-3 岁月龄自适应早教工作台

## 1. 背景与目标

妈妈需要一个随宝宝成长自动适应的早教工作台，而不是固定在某个月龄的静态清单。当前宝宝为 4 个多月的女宝（会趴卧、会翻身），但产品应覆盖 0-3 岁全程，依据宝宝出生日期自动换算月龄并切换对应年龄段内容。

目标：

- 家长一次设置出生日期，系统长期跟随成长自动更新内容。
- 每天可直接落地：左侧打勾、右侧滚动浏览全部模块。
- 全部内容使用真实生活物品、实物操作优先，低成本、不费妈、不超前。
- 数据保存在本机，支持手动导出与导入。

## 2. 核心用户与使用场景

- 主用户：妈妈（每天下午约 1 小时使用）。
- 被陪伴对象：宝宝（0-3 岁，屏幕不让宝宝看）。
- 典型流程：首次设置宝宝档案 → 每天打开看今日内容 → 陪玩打勾 → 每周主题自动轮换 → 跨越月龄时内容自动升级。

## 3. 非目标（明确不做）

- 不做医疗诊断，发育观察仅为参考，最终以儿保医生评估为准。
- 不给宝宝任何屏幕早教，屏幕只给家长看。
- 不做闪卡灌输、不识字超前学、不机械跟读、不压力训练、不复杂任务。
- 不在医生允许前添加辅食或通过早教活动喂食。
- 不生成未经人工审核的随机内容。

## 4. 功能需求

### F1 宝宝档案与月龄初始化

- 首次使用进入设置页：昵称、出生日期、每日可用时间段、是否启用英文模块。
- 系统按出生日期自动计算当前月龄，并映射到对应年龄段。
- 支持手动预览“下一月龄”内容，但不改变实际月龄判定。

### F2 月龄自适应内容

- 内容按年龄段组织，跨段自动切换。
- 覆盖 0-3 岁，共 8 个年龄段（见设计方案与内容文档）。
- 每个年龄段的内容、观察项、教具、空间、英文侧重均独立配置、可独立维护。
- 跨越月龄时保留历史记录并按年龄段归档，可回看。

### F3 每日五大模块 + 观察提醒

每日固定生成并展示以下板块（左侧打勾，右侧上下滚动）：

1. 精细动作：按年龄给 3 个专注力小游戏。
2. 语言启蒙：按年龄给高频口语话术。
3. 认知启蒙：按年龄给搭配引导方式。
4. 英文启蒙短句：按年龄给磨耳朵歌、口语短句、TPR 动作。
5. 大运动 + 感统：按年龄给对应运动与感统玩法。
6. 发育观察重点与养育提醒：当日观察项 + 安全 / 作息提醒。

### F4 每周主题循环系统

- 固定 7 周主题轮换：颜色视觉周、声音节奏周、触感材质周、宝宝身体周、日常物品周、自然光影周、亲子互动周。
- 同一主题在不同年龄段会呈现不同玩法，重复且渐进。
- 幼儿期（13 月龄后）可扩展主题：动物、水果、五官、家务、自然等，仍保持 7 周轮换。

### F5 活动库

- 按“年龄段 × 发展领域 × 主题”三条件筛选。
- 发展领域：精细动作、大运动、语言认知、感官探索、生活技能、亲子互动。
- 主题：颜色、声音、触感、身体、日常物品、自然、韵律、动物、水果、家务等。
- 每条活动含：推荐月龄范围、准备物品、玩法、安全提示。
- 全部使用真实生活物品，实物操作优于玩具。

### F6 发育观察记录

- 按年龄段提供对应观察项（儿保参考），分为大运动、精细动作、语言、认知、社交情绪五类。
- 打勾自动保存本机。
- 跨越月龄后，旧年龄段记录归档保存、可回看，并按新年龄段提供新观察项。
- 注明“参考内容，最终以儿保医生评估为准”。

### F7 教具清单

- 按年龄段提供 4 类清单：家居物品、食物类、低成本进阶、DIY 教具。
- 标注用途与风险提示，随月龄变化。

### F8 空间布置

- 五个功能区：运动区、操作区、感官区、阅读角、收纳区。
- 按月龄给出布置要求与安全检查清单。

### F9 英文启蒙

- 三个模块：SSS 磨耳朵歌、亲子口语短句、TPR 动作。
- 原则：只磨耳朵、建立画面对应，不认读、不拼写、无压力。
- 短句支持语音播报（浏览器 TTS）；儿歌因版权原因由用户上传音频后播放。

### F10 数据与备份

- 勾选、观察记录、宝宝档案均保存在本机。
- 提供导出 JSON 与导入 JSON。
- 换设备时通过导出/导入恢复。

### F11 导航与布局

- 左侧纵向导航栏常驻、不收起，可爱彩色图标 + 文字；侧栏宽度适中。
- 右侧一次展示全部模块，上下滚动浏览，不溢出。
- 点击今日模块时展示其子模块，可与右侧内容联动。

### F12 部署与多设备

- PWA 单页应用，可添加到手机桌面当 App 使用。
- 保留离线可用能力。
- 正式环境生成在线链接，支持多设备访问；数据同步默认为本机 + 手动导出导入。

## 5. 内容规则

1. 专注玩耍时不打断、不提问、不干预。
2. 优先真实食材 / 实物，优于玩具教学。
3. 内容融入日常，不专门坐教、不上课式学习。
4. 任务极简、低成本、随手可做、不费妈。
5. 尊重宝宝节奏，不强迫展示、不攀比、不超前。
6. 所有内容以大运动、精细、语言、认知、社交等儿保参考为基准，标注安全提示。

## 6. 验收标准

- 首次设置出生日期后，今日内容随月龄自动切换，无需人工编辑。
- 8 个年龄段各有独立且可落地的内容、观察项、教具、空间与英文方案。
- 每个年龄段每日 5 大模块 + 观察提醒可全部显示并上下滚动，左侧可打勾。
- 勾选与观察记录刷新后保留，导出导入可恢复。
- 跨越月龄后旧记录归档可回看，新内容自动启用。
- 移动端可添加到主屏幕，英文短句可语音播报。
- 部署后生成多设备可访问的在线链接。
