# 0-3 岁全龄早教内容设计

本文档给出 8 个年龄段的完整内容设计，作为需求与方案的配套。每个年龄段按统一模板输出：阶段特点、每日五大模块 + 观察提醒、观察重点、教具、空间与安全、英文启蒙、主题适配。

原则：融入日常、不坐教；实物优先；极简低成本；尊重宝宝节奏、不超前；内容需人工审核并标注安全提示。

---

## 段 1：0-3 个月（新生儿 · 感官唤醒期）

**阶段特点**：以感官唤醒和亲子联结为主，宝宝以注视、追视、听声、被动运动为核心。

### 每日五大模块
- 精细动作（3）：触碰不同材质（棉/绒/毛巾）、轻握摇铃（被动给）、看自己的小手小脚。
- 语言启蒙（2-3）：妈妈温柔旁白（喂奶、换尿布）、面对面发出“啊～”并等回应、轻轻哼唱。
- 认知启蒙（2）：高对比黑白红图注视、声音来源寻找、妈妈人脸注视。
- 英文启蒙：1 首磨耳朵简单儿歌（Hello / 摇篮曲）、1-2 句妈妈英文短句（语调温柔）、TPR 妈妈做给宝宝看。
- 大运动 + 感统（3）：俯卧短时抬头、仰卧自由活动四肢、轻柔摇抱、追视移动玩具。
- 观察提醒：今日观察逗笑、追视、对声反应、抬头迹象、睡眠安全。

### 观察重点
- 大运动：俯卧可短暂抬头、能转动头部。
- 精细：抓握反射存在、手碰物有反应。
- 语言：对声音转头、可发“啊/咕”。
- 认知：追视移动红球、注视人脸。
- 社交：被逗可有微笑、认妈妈声音。

### 教具
- 家居：棉布、绒布、红纱巾、轻摇铃、安全镜子。
- 食物类：无（不触碰）。
- 低成本进阶：黑白红视觉挂图、安抚巾。
- DIY：密封感官瓶（摇晃听声）、黑白红卡（环境布置）。

### 空间与安全
- 五大功能区以感官区、阅读角为主。
- 安全：床上无多余软枕毛毯、防闷、无入口小件、避免强光直射眼睛。

### 英文侧重
- 以听和语调为主：轻柔磨耳朵。
- 示例：Hello, baby. / Peek-a-boo!（妈妈做动作）。

### 主题适配
- 颜色（黑白红）、声音、光影、亲子互动，每天简单重复。

## 段 2：4-6 个月（翻身 · 前坐期）★当前宝宝所在段

**阶段特点**：会趴卧、学翻身，前坐准备期；抓握、咿呀、追视更成熟。

### 每日五大模块
- 精细动作（3）：抓握摇铃、双手抱软球、趴卧够纱巾；其他可换：撕大纸巾、抓妈妈手指、摸不同布料。
- 语言启蒙（2-3）：换尿布/喂奶旁白、咿呀对话回应、指物命名（灯、球、鼻子）。
- 认知启蒙（2-3）：红球追视 180 度、声源找方向、照镜子、纱巾躲猫猫、触摸凉暖材质。
- 英文启蒙：1 首 SSS 磨耳朵、2-3 句口语短句（TTS 可播报）、1 个 TPR（妈妈做）。
- 大运动 + 感统（3）：俯卧抬头/肘撑、辅助自主翻身、轻柔摇抱、抱姿看世界、踢腿蹬床。
- 观察提醒：观察翻身、逗笑、咿呀回应、抓物、认人；提醒趴练看护与防跌落。

### 观察重点
- 大运动：俯卧抬头、肘撑、可翻身、拉坐头稳。
- 精细：伸手抓物、双手抱物、抓握摇铃、看手玩手。
- 语言：咿呀、笑出声、对声转头、回应妈妈语音。
- 认知：追视 180 度、找声源、看镜有反应、躲猫猫有期待。
- 社交：被逗笑、认妈妈、表情表达需求。

### 教具
- 家居：红纱巾、轻摇铃、不锈钢勺/碗、安全镜子、棉绒毛巾。
- 食物类：橙子、苹果看闻摸（不入口）。
- 低成本进阶：不同材质软球、安抚巾、布书、安全牙胶。
- DIY：密封感官瓶、纸筒传声筒、黑白红挂图。

### 空间与安全
- 运动区（爬行垫+落地镜）、操作区（低筐）、感官区（布料/视听）、阅读角（布书）、收纳区（低柜+锁）。
- 安全：玩具大于拳头、无小件、防翻身跌落、防口鼻、防阳光直射。

### 英文侧重
- 磨耳朵为主，TPR 由妈妈做给宝宝看。
- 示例：Good morning, sweetie! / Let's clap your hands. / This is red.

### 主题适配
- 颜色（红白黑）、声音、触感、身体、日常物品、自然光影、亲子互动，7 周轮换。

## 段 3：7-9 个月（独坐 · 爬行期）

**阶段特点**：从坐到爬，身体移动能力爆发；手指分化、模仿、认生明显。

### 每日五大模块
- 精细动作（3）：拇指食指取大块、对敲两块积木、倒手换物；其他可换：撕纸、拉玩具、拍打桌面、盒子里取小物（大块）。
- 语言启蒙（3）：听懂简单词（“杯子”“球球”）、教做“拜拜/再见”、模仿发声、指认五官。
- 认知启蒙（3）：物体恒存（藏玩具再找出来）、按按钮看亮/响（因果）、照镜子玩、模仿拍手。
- 英文启蒙：1 首磨耳朵歌、2-3 短句、1 TPR（拍手/拜拜）。
- 大运动 + 感统（3）：独坐、匍匐/爬行、从趴到坐、扶站初尝试；可加爬坡、爬隧道、爬行追玩具。
- 观察提醒：观察独坐、爬、拇指取物、说 ba/da、认生、模仿。

### 观察重点
- 大运动：独坐、坐稳、爬行、从趴到坐、扶站尝试。
- 精细：拇食指取物（大块）、对敲、倒手、拍打。
- 语言：听懂简单指令、指认、拜拜、模仿发声。
- 认知：物体恒存、因果、模仿动作。
- 社交：认生/认亲密人、有需求表达。

### 教具
- 家居：大块积木、盒子、挂钩、毛巾、吸管杯（把玩）。
- 食物类：蔬菜/水果看摸（不入口）。
- 低成本进阶：推拉玩具、隧道（纸箱）、牙胶、厚纸布书。
- DIY：藏宝盒、纸箱隧道、吊挂玩具。

### 空间与安全
- 爬行区铺软垫并围护栏、插座保护、家具尖角包边、防夹手、防倾倒。
- 安全：爬行区无小件、无绳索、家具固定。

### 英文侧重
- 磨耳朵 + 简单动作词 + 指认。
- 示例：Wave bye-bye! / Where is the ball? / Clap clap!

### 主题适配
- 声音、触感、日常物品、身体、颜色、自然、亲子互动轮换。

## 段 4：10-12 个月（扶站 · 扶走期）

**阶段特点**：从扶站到扶走，捏取更精细；语言从模仿到有意识叫爸妈。

### 每日五大模块
- 精细动作（3）：拇食指捏小物（大块）、翻厚纸板书、盖瓶盖；其他：开抽屉、取放积木、舀、套杯。
- 语言启蒙（3）：听名字回应、有意识叫“妈妈/爸爸”、指认身体/物品、模仿词汇、挥手再见。
- 认知启蒙（3）：指认日常物品、简单配对、因果（灯/开关）、藏找巩固、指认颜色。
- 英文启蒙：1 首磨耳朵歌、短句、TPR（指认 body parts）。
- 大运动 + 感统（3）：扶站、独站数秒、扶走、蹲下站起；可加投球、爬台阶（低、扶）。
- 观察提醒：观察扶走/独站、捏小物、有意识叫爸妈、指认、拜拜。

### 观察重点
- 大运动：扶站、独站片刻、扶走、蹲起。
- 精细：拇食指捏、翻书、盖盖、取放。
- 语言：听名回应、有意识叫爸妈、指认、拜拜。
- 认知：指认物品、简单配对、因果。
- 社交：模仿手势、表达意愿、认生/依恋。

### 教具
- 家居：厚纸板绘本、形状盒、套杯、可抓握小球、拍手歌。
- 食物类：软质食物看摸（不入口或按医生建议）。
- 低成本进阶：推拉学步玩具、布书、摇铃球。
- DIY：藏宝盒、纸箱踏步台阶（低矮、看护）。

### 空间与安全
- 扶站区加固、围栏；防夹手、防坠、防倾倒。
- 安全：捏小物期严防入口；家具上锁；小物监管。

### 英文侧重
- 磨耳朵 + 简单名词指认 + TPR body parts。
- 示例：Where is your nose? / This is red. / Bye-bye!

### 主题适配
- 颜色、身体、日常物品、声音、触感、自然、亲子轮换。

## 段 5：13-18 个月（学步 · 初语言期）

**阶段特点**：独走不稳到走稳，蹲、弯腰、拾物；词汇量快速增加，开始涂鸦与独立进食。

### 每日五大模块
- 精细动作（3）：舀豆/倒水（大容器）、叠 2-3 块积木、翻硬页书；其他：撕贴、大动作涂鸦、穿大珠、盖盖。
- 语言启蒙（3）：听懂并执行简单指令、说两字词、指认身体五官、简单短句。
- 认知启蒙（3）：颜色初识、大小比较、简单配对、日常物品用途、藏找、推拉开合。
- 英文启蒙：1 首磨耳朵歌、短句、TPR（动作词）。
- 大运动 + 感统（3）：独走、蹲下站起、弯腰拾物、扶栏上台阶；可加踢球、抛球。
- 观察提醒：观察独走、词量、听指令、模仿、涂鸦尝试、独立进食。

### 观察重点
- 大运动：独走、走稳、蹲起、拾物。
- 精细：舀倒、叠积木、翻页、涂鸦尝试。
- 语言：词量增加、两字词、听指令、指认五官。
- 认知：颜色/大小初识、配对、物品用途。
- 生活技能：独立用勺、脱鞋袜、洗手、收玩具。

### 教具
- 家居：舀勺碗、叠杯、大画笔、纸、球、伞/盒。
- 食物类：安全水果/蔬菜片（按医生建议允许时）。
- 低成本进阶：形状盒、配对卡（实物）、大块拼图。
- DIY：大米/豆舀盒（看护）、纸箱爬梯、感官瓶。

### 空间与安全
- 走稳区软包、防磕碰；桌角防护；小物监管；家具固定。
- 安全：防跑跌、防夹手、防入口。

### 英文侧重
- 磨耳朵 + 动作词/名词 + 简短指令 TPR。
- 示例：Let's walk! / Touch your toes. / This is a ball.

### 主题适配
- 颜色、声音、身体、日常物品、自然、韵律、家务启发。

## 段 6：19-24 个月（词汇爆发 · 跑跳期）

**阶段特点**：词汇爆发、可说短句；跑跳、分类、自理意识增强。

### 每日五大模块
- 精细动作（3）：穿大珠、叠高积木、拧瓶盖、安全剪刀剪纸、涂色（边界内）、配对。
- 语言启蒙（3）：丰富词汇（动物/水果/颜色）、说两三个词短句、唱简单儿歌、回答简单问题。
- 认知启蒙（3）：颜色/形状/大小分类、动物/水果命名、简单逻辑、记忆配对游戏、日常规则。
- 英文启蒙：1 首磨耳朵歌、单词指认（颜色/动物）、短句、TPR。
- 大运动 + 感统（3）：跑、跳离地尝试、上下楼梯（扶）、抛接球、平衡（低）。
- 观察提醒：观察词汇、短句、跳跃、分类、自理、社交互动。

### 观察重点
- 大运动：跑、跳尝试、扶楼梯、抛接球。
- 精细：穿珠、叠高、拧盖、剪纸、涂色。
- 语言：词汇爆发、短句、唱儿歌。
- 认知：颜色/形状分类、命名动物水果、简单逻辑。
- 生活技能：独立吃饭、穿脱部分衣服、如厕意识、收玩具。

### 教具
- 家居：大珠、积木、安全剪刀、配对卡、球、小台阶。
- 食物类：安全蔬果（允许时）。
- 低成本进阶：形状分类盒、拼图（大块）、画纸彩笔。
- DIY：分类盒、感官米盒（看护）、纸箱平衡桥（低）。

### 空间与安全
- 蹦跳区软垫、家具固定、防磕碰；小物监管。
- 安全：防跑跳跌倒、防入口、户外看护。

### 英文侧重
- 磨耳朵 + 名词指认（颜色/动物）+ 短句 + TPR。
- 示例：What color is this? / It's a cat. / Jump, jump!

### 主题适配
- 颜色、动物、水果、声音、身体、日常物品、自然、家务、亲子轮换。

## 段 7：25-30 个月（模仿 · 自理 · 社交期）

**阶段特点**：句子更完整，剪刀与平衡能力提升，自理和社交明显。

### 每日五大模块
- 精细动作（3）：沿直线剪、画圆/直线、穿珠、搭较复杂积木、大块拼图。
- 语言启蒙（3）：说完整短句、问“这是什么”、描述看到的东西、听故事并回应。
- 认知启蒙（3）：颜色/形状/大小/多少、排序、简单分类、记忆配对、遵守简单规则。
- 英文启蒙：1 首磨耳朵歌、歌谣动作、简单对话指令、TPR。
- 大运动 + 感统（3）：单脚平衡尝试、跳远、接球、攀爬小器械、骑小三轮车。
- 观察提醒：观察句子、提问、平衡、剪刀、自理、分享。

### 观察重点
- 大运动：平衡、跳远、接球、攀爬、骑小三轮。
- 精细：用剪刀、画圆线、穿珠、拼图。
- 语言：完整句子、提问、描述、唱整首儿歌。
- 认知：排序、分类、多少大小、记忆游戏。
- 生活技能：独立穿衣、如厕训练、洗手刷牙、帮忙家务。

### 教具
- 家居：安全剪刀、拼图、穿珠、积木、三轮车、绘本。
- 食物类：安全蔬果（允许时）、帮忙摆餐具。
- 低成本进阶：分类盒、蜡笔、大块乐高类。
- DIY：创意画、家务小帮手（递抹布、放玩具）。

### 空间与安全
- 运动器械防摔、家具固定、户外看护；剪刀监督。
- 安全：攀爬/平衡防跌、器械检查、小物用后收纳。

### 英文侧重
- 磨耳朵 + 简单对话 + 歌谣动作 + TPR。
- 示例：Can you find the red one? / Let's sing together!

### 主题适配
- 动物、水果、颜色、身体、日常物品、自然、家务、韵律轮换，加入简单角色扮演。

## 段 8：31-36 个月（入园准备 · 语言成熟期）

**阶段特点**：叙事与问题逻辑增强，自理独立，为入园做社交与习惯准备。

### 每日五大模块
- 精细动作（3）：精细剪刀、握笔描画、系扣/拉链尝试、较复杂拼图、建构游戏。
- 语言启蒙（3）：复杂叙述、问句理解、时间概念（今天/明天）、社交语言、角色扮演。
- 认知启蒙（3）：数数概念（1-10）、大小/多少/长短、分类归位、逻辑推理、记忆游戏。
- 英文启蒙：1 首磨耳朵歌、简短对话、歌谣、TPR、绘本听读。
- 大运动 + 感统（3）：骑三轮车、单脚跳、平衡、投掷、球类、攀爬。
- 观察提醒：观察叙述、数概念、自理、情绪社交、专注时长、入园准备。

### 观察重点
- 大运动：三轮车、单脚跳、平衡、投掷。
- 精细：精细剪刀、握笔、系扣/拉链、拼图、建构。
- 语言：复杂叙述、问句、时间概念、角色扮演。
- 认知：数概念、长短多少、分类归位、逻辑。
- 生活技能：独立如厕、穿衣、进餐、整理、情绪表达。

### 教具
- 家居：拼图、建构、画笔、绘本、三轮车、安全剪刀。
- 食物类：安全蔬果、参与简单备餐（看护）。
- 低成本进阶：多米诺、串珠、涂色本、排序卡。
- DIY：情景角色扮演、家务小任务、创意美术。

### 空间与安全
- 户外安全、器械监督、防户外风险；养成收纳与安全习惯。
- 安全：骑行/攀爬防护、远离道路、器械规范。

### 英文侧重
- 磨耳朵 + 简短对话 + 歌谣 + TPR + 绘本听读。

### 主题适配

## 统一定义

- **每周主题（7 周轮换）**：颜色、声音、触感、身体、日常物品、自然、亲子互动；13 月龄后扩展动物、水果、家务等，仍 7 周轮换。
- **五大模块 + 观察提醒**：在所有年龄段结构一致，内容随年龄段变化。
- **内容安全**：所有玩法标注安全提示，高危操作（入口、跌落、夹手、器械）尤为强调。
- **数据**：观察、打勾、档案存本机，随月龄归档，支持导出导入。
- **底线**：不超前、不考核、不屏幕早教给宝宝、实物优先、人工审核。
