# 设计方案：0-3 岁月龄自适应早教工作台

## 1. 总体架构

采用“内容数据层 + 渲染层”的单页应用结构，内容与界面解耦，便于按年龄维护：

- 内容数据层：预置的手工维护内容库，按年龄带、领域、主题、每日模板组织。
- 月龄判定层：由出生日期实时计算当前月龄并映射到年龄带。
- 计划生成层：用“年龄带 + 当前日期 + 周主题”确定性轮换生成每日内容。
- 渲染层：左侧导航 + 右侧板块滚动视图。
- 数据层：本机存储（localStorage / IndexedDB），导出导入 JSON。

## 2. 数据模型

### 宝宝档案（BabyProfile）

```json
{
  "nickname": "之之",
  "birthDate": "2026-04-01",
  "dailyTimeSlot": "每天下午约1小时",
  "enableEnglish": true
}
```

### 年龄带（AgeBand）

```json
{
  "key": "4-6m",
  "name": "4-6个月",
  "minMonths": 4,
  "maxMonths": 6,
  "stage": "翻身期 · 前坐期",
  "desc": "翻身、前坐准备、伸手够物、咿呀对话"
}
```

### 内容条目（ContentEntry）

```json
{
  "id": "4-6m-fine-03",
  "bandKey": "4-6m",
  "domain": "精细动作",
  "theme": "触感",
  "title": "趴卧够纱巾",
  "monthsLabel": "4-6月",
  "materials": "红纱巾",
  "how": "宝宝俯卧时，在伸手可及处放一条红纱巾，让他自主去够和抓。",
  "safety": "全程看护，旁边无遮挡。"
}
```

### 每日模块（DailyModule）

由计划生成层按年龄带从对应内容池抽取，结构稳定：

```json
{
  "moduleKey": "fine",
  "title": "精细动作",
  "items": [ { "id": "...", "title": "...", "how": "...", "note": "..." } ]
}
```

### 观察项（ObservationItem）

```json
{ "id": "4-6m-observe-motor-01", "bandKey": "4-6m", "category": "大运动", "label": "能自主翻身" }
```

### 本地存储键

- `baby.profile.v1`：宝宝档案。
- `baby.dailyChecks.v1`：每日打勾记录（按日期）。
- `baby.observationChecks.v1`：观察记录（按条目 id）。
- `baby.archives.v1`：跨月龄归档。
- `baby-audio`（IndexedDB）：用户上传的儿歌音频。

## 3. 年龄段划分（0-3 岁，共 8 段）

| 段 | 月龄 | 关键期 | 说明 |
|---|---|---|---|
| 0-3m | 0-3 | 新生儿·感官唤醒 | 追视、抓握反射、听声、表情社交 |
| 4-6m | 4-6 | 翻身·前坐 | 翻身、肘撑、伸手够物、咿呀对话 |
| 7-9m | 7-9 | 独坐·爬行 | 独坐、爬行、拇指取物、模仿 |
| 10-12m | 10-12 | 扶站·扶走 | 扶走、拇食指捏、有意识叫爸妈 |
| 13-18m | 13-18 | 学步·初语言 | 独走、蹲、初词、涂鸦、独立进食 |
| 19-24m | 19-24 | 词汇爆发·跑跳 | 跑跳、短句、分类、自理意识 |
| 25-30m | 25-30 | 模仿·自理·社交 | 剪刀、平衡、句子、如厕意识、分享 |
| 31-36m | 31-36 | 入园准备 | 叙述、数概念、独立自理、情绪社交 |

## 4. 计划生成逻辑

1. 当前月龄 = 由出生日期计算得出，映射到年龄带 `band`。
2. 周主题 = 由 ISO 周数取模得到（7 周轮换）。
3. 每日内容 = 从 `band` 对应模块内容池，用“日序号 + 模块偏移”确定性抽取：
   - 精细动作：抽 3 条；
   - 语言启蒙：抽 2-3 条话术；
   - 认知启蒙：抽 2-3 条；
   - 英文启蒙：抽 1 首歌 + 2-3 短句 + 1 个 TPR；
   - 大运动感统：抽 3 条；
   - 观察提醒：抽 2-3 条。
4. 结果稳定可复现：同一天、同年龄段、同主题必然得到相同内容，刷新不跳动。

## 5. 内容维护策略

- 以手工精选内容库为主（可落地、稳定、安全），生命周期长。
- 每个年龄带 × 每个模块配置独立内容池，条目数建议 10 条以上以保证轮换多样性。
- 内容必须由人工审核并标注安全提示；不以未审核的 AI 生成结果直接上线。
- 后续可提供“AI 草稿 + 人工审核”的能力作为增量，但不作为默认。

## 6. 用户流程

1. 首次使用：设置昵称、出生日期、每日时段。
2. 日常使用：打开“今日”→ 看当前年龄带内容 → 陪玩打勾。
3. 周更：每周主题自动轮换，同主题按年龄渐进。
4. 月更：月龄跨越边界时自动切换年龄带，旧记录归档。
5. 备份：到“我的”导出/导入 JSON。

## 7. 技术栈与部署

- 前端：React + Vite + TypeScript，PWA（service worker + manifest），本地存储。
- 语音：浏览器 Web Speech API 播报英文短句；儿歌音频由用户上传并本地存储。
- 部署：静态站点托管，可选 GitHub Pages / Vercel / Netlify / 腾讯云；生成可添加到主屏幕的 PWA 链接。
- 多设备：默认本机数据 + 手动导出导入；如需自动同步再引入账号云同步（需另行确认）。

## 8. 分阶段落地

- 阶段 A：完成 4-6 月龄原型与交互布局验证。
- 阶段 B：接入宝宝档案与月龄判定，建立 8 个年龄带模型。
- 阶段 C（当前）：0-3 岁 8 个年龄段每日内容池与发育观察已接入，构建验证通过。
- 阶段 C（当前）：0-3 岁 8 个年龄段的每日内容、发育观察、活动库与英文池已接入，构建与浏览器验证通过。
- 阶段 D：上线部署生成在线链接，适配添加主屏幕与多设备访问。

## 9. 风险与回滚

- 内容安全风险：所有内容人工审核、标注安全提示，高危操作（入口、跌落、夹手）加醒目提醒。
- 月龄误判风险：支持手动调整月龄与查看下一月龄预告。
- 数据丢失风险：本机存储 + 定期导出建议；上线后可选云同步。
- 内容规模风险：0-3 岁内容池已覆盖 8 个年龄带，后续按月龄补充新玩法并保持质量审核。
