# 0-3 岁全龄早教内容设计（后续年龄段详细版：7-9 月至 31-36 月）

本文档与 `CONTENT_0_3.md` 配套，把 7-9 月、10-12 月、13-18 月、19-24 月、25-30 月、31-36 月共 6 个年龄段的“内容需求”落到可录入 App 的池子：每日模块示例、观察项、教具、空间安全、英文侧重、主题适配。

## 内容作者规范

每个年龄段至少满足以下池子规模，保证每日自动轮换不重样、可落地：

- 精细动作：6-8 条（每日抽 3）。
- 语言启蒙：6-8 条（每日抽 2-3）。
- 认知启蒙：6-8 条（每日抽 2-3）。
- 大运动 + 感统：6-8 条（每日抽 3）。
- 英文：歌单 6 首 + 口语 8-10 句 + TPR 6 个（每日抽 1 歌、2 句、1 动作）。
- 观察提醒：6-8 条（每日抽 2-3）。
- 观察项：五大类，每类 5 条。
- 教具：家居 / 食物类 / 低成本进阶 / DIY 四类。
- 空间与安全：五大功能区原则不变，安全清单按月龄更新。
- 底线：不超前、不考核、实物优先、全部人工审核并标注安全提示。

## 段 3：7-9 个月（独坐 · 爬行期）

### 阶段特点
从坐到爬，身体移动能力爆发；手指分化、模仿、认生明显。重点：独坐、爬行、拇指取物、模仿、物体恒存。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 拇食指取大块：把大块积木放在眼前，让宝宝用拇食指尝试捏取。
  2. 对敲积木：两只手各拿一块积木，自己敲响。
  3. 倒手换物：拿玩具从一只手换到另一只手。
  4. 撕纸探索：给大张纸自己撕、揉。
  5. 拉玩具：让宝宝拉扯带短绳的安全玩具。
  6. 拍打桌面/鼓面：自己拍打出声音。
  7. 盒中取物：从浅盒里拿出大块物品。
- 语言启蒙（每日抽 2-3）：
  1. 听懂简单词：听到“球球 / 杯子”时妈妈指物并重复。
  2. 做拜拜：边说“再见”边挥手做给宝宝看。
  3. 模仿发声：回应宝宝 ba-ba、da-da，等他再发。
  4. 指认五官：指着鼻子、眼睛、嘴巴慢慢说。
  5. 玩具命名：每次给玩具都说名字（球、铃、杯）。
  6. 洗澡互动：洗澡时描述水温、毛巾、水花。
- 认知启蒙（每日抽 2-3）：
  1. 物体恒存：用纱巾盖住玩具，问“球球呢？”再揭开。
  2. 因果按键：按亮小夜灯或按响玩具，看因果。
  3. 照镜子玩：拍镜中的自己，听名字回应。
  4. 模仿拍手：妈妈拍手，让宝宝看了之后自己试。
  5. 开关门：反复开合柜门、抽屉，观察变化。
- 大运动 + 感统（每日抽 3）：
  1. 独坐：垫上坐稳，前方放玩具自取自玩。
  2. 坐爬转换：从坐姿慢慢转成趴姿爬行。
  3. 爬行追玩具：前方放玩具，让宝宝自己爬去拿。
  4. 爬坡 / 隧道：用纸箱、斜坡垫做低矮爬行通道。
  5. 扶站尝试：扶着沙发或围栏尝试站一下。
  6. 踢腿蹬床：仰卧蹬腿，妈妈用手轻挡。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：能不能独坐并坐稳 1-2 分钟？
  2. 观察：会不会爬行或匍匐移动？
  3. 观察：会不会用拇食指捏大块积木？
  4. 观察：会不会说 ba-ba、da-da 一类音节？
  5. 提醒：爬行区清空小件、绳索，全程看护。
  6. 提醒：扶站只做尝试，不强迫站立。

### 观察重点（五类，每类 5 条）
- 大运动：独坐；坐稳；爬行；从趴到坐；扶站尝试。
- 精细动作：拇食指取大块；对敲；倒手；撕纸；拍打。
- 语言：听懂简单词；做拜拜；模仿发声；指认五官；回应名字。
- 认知：物体恒存；因果；模仿动作；照镜子；开关门好奇。
- 社交情绪：认生；认亲密人；用表情表达需求；被逗笑；主动看人。

### 教具
- 家居：大块积木、盒子、毛巾、挂钩、吸管杯（把玩）。
- 食物类：安全蔬果看摸（不入口，遵医嘱）。
- 低成本进阶：推拉玩具、纸箱隧道、牙胶、厚纸布书。
- DIY：藏宝盒、纸箱隧道、吊挂玩具、感官瓶。

### 空间与安全
- 五大功能区：运动区以爬行垫 + 围栏为主，操作区放大块玩具筐，感官区保留布料与视听，阅读角用布书，收纳区低柜上锁。
- 安全清单：爬行区无小件；插座加保护；家具固定防倾倒；防夹手；防跌落；爬行垫每天清洁。

### 英文侧重
- 磨耳朵 + 简单动作词 + 指认。
- 示例：`Wave bye-bye!` / `Where is the ball?` / `Clap clap!`

### 主题适配
- 声音、触感、日常物品、身体、颜色、自然、亲子互动 7 周轮换；同主题玩法比 0-6 月更主动。

## 段 4：10-12 个月（扶站 · 扶走期）

### 阶段特点
从扶站到扶走，捏取更精细；语言从模仿到有意识叫爸妈。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 拇食指捏大块：捏起大块积木或软木塞。
  2. 翻厚纸板书：自己一页页翻硬纸板书。
  3. 盖瓶盖：把盖子盖到瓶口再拿开。
  4. 开抽屉 / 开盒：拉开柜门、抽屉找东西。
  5. 放取积木：把积木放进杯子再倒出来。
  6. 舀物：用大勺舀豆类（看护下）。
  7. 套杯：把套杯套进去再拿出来。
- 语言启蒙（每日抽 2-3）：
  1. 听名回应：叫名字时转头看。
  2. 有意识叫爸妈：示范“妈妈、爸爸”，不纠正。
  3. 指认物品：听到“灯灯”就指。
  4. 模仿词汇：跟说 ba、ma、wa 等音。
  5. 挥手再见：说“再见”时挥手做给宝宝看。
  6. 简单指令：说“拿来球球”等一步指令。
- 认知启蒙（每日抽 2-3）：
  1. 指认日常物品：灯、球、杯、鞋。
  2. 简单配对：两两配对相同物品。
  3. 因果探索：按开关开灯、开合手电筒。
  4. 藏找巩固：把玩具藏进盒里再打开找。
  5. 颜色初识：指着红、蓝、黄物品看。
- 大运动 + 感统（每日抽 3）：
  1. 扶站：扶着围栏/沙发站一会儿。
  2. 独站尝试：妈妈轻扶后放手数秒。
  3. 扶走：扶围栏或推小车走几步。
  4. 蹲下站起：捡起地上的玩具站起来。
  5. 投球：手掌抓大球放进筐里。
  6. 上矮台阶：扶着上下低矮台阶/垫子。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：能不能扶站或独站数秒？
  2. 观察：会不会扶走或推物走？
  3. 观察：有没有有意识叫爸妈？
  4. 观察：会不会捏小物、盖盖、翻书？
  5. 提醒：扶站区加固围栏，防倾倒。
  6. 提醒：小物监管，严防入口。

### 观察重点（五类，每类 5 条）
- 大运动：扶站；独站数秒；扶走；蹲下站起；投球。
- 精细动作：拇食指捏；翻厚纸板书；盖瓶盖；放取积木；舀物。
- 语言：听名回应；有意识叫爸妈；指认；拜拜；模仿词音。
- 认知：指认物品；简单配对；因果；藏找；颜色初识。
- 社交情绪：模仿手势；表达意愿；认生/依恋；用表情回应；主动递物。

### 教具
- 家居：厚纸板绘本、形状盒、套杯、可抓握小球、拍手歌、抱枕。
- 食物类：安全蔬果看摸（不入口，遵医嘱）。
- 低成本进阶：推拉学步玩具、布书、摇铃球、开口收纳盒。
- DIY：藏宝盒、低矮踏步垫、纸箱推车。

### 空间与安全
- 扶站区加固围栏；家具固定；防夹手；防坠；防倾倒；小物放进带盖筐。
- 安全清单：桌角防护；插座保护；抽屉锁；楼梯口护栏；重物不放在可攀爬处。

### 英文侧重
- 磨耳朵 + 简单名词指认 + TPR body parts。
- 示例：`Where is your nose?` / `This is red.` / `Bye-bye!`

### 主题适配
- 颜色、身体、日常物品、声音、触感、自然、亲子互动轮换。

## 段 5：13-18 个月（学步 · 初语言期）

### 阶段特点
独走不稳到走稳，蹲、弯腰、拾物；词汇量快速增加，开始涂鸦与独立进食。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 舀豆：用大勺把豆子从一碗舀到另一碗（看护）。
  2. 倒水：把小杯中水倒进大盆（看护）。
  3. 叠积木：尝试叠 2-3 块积木。
  4. 翻硬页书：自己翻书找熟悉的图。
  5. 撕贴：撕彩纸贴在大纸上。
  6. 大动作涂鸦：抓粗蜡笔在纸上画。
  7. 穿大珠：穿孔径大的木质珠。
  8. 盖盖：盖各种瓶盖、套杯。
- 语言启蒙（每日抽 2-3）：
  1. 说两字词：妈妈说“球球、抱抱、奶”。
  2. 一步指令：说“把球给妈妈”并示范。
  3. 指认五官/物品：指眼睛、鼻子、杯子。
  4. 简单短句：听“娃娃在坐”等 2-3 字短句。
  5. 唱简单儿歌：一起哼《小星星》等。
  6. 看图说话：指绘本说“狗狗、猫猫”。
- 认知启蒙（每日抽 2-3）：
  1. 颜色初识：指着红蓝黄物品说颜色。
  2. 大小比较：对比大球和小球，说“大、小”。
  3. 配对：把相同颜色/形状归到一起。
  4. 物品用途：问“杯子喝水、梳子梳头”。
  5. 藏找：在盒子里、毛巾下找玩具。
  6. 推拉开合：开合门、抽屉、拉链。
- 大运动 + 感统（每日抽 3）：
  1. 独走：自由在软垫上走，走不稳就坐。
  2. 蹲下站起：捡地上玩具再站起来。
  3. 弯腰拾物：弯腰捡大球。
  4. 扶栏上台阶：扶手上低矮台阶。
  5. 踢球：站立踢软球。
  6. 抛球：双手把大球抛出去。
  7. 推车走：推小推车走直线。
- 生活技能（融入每日）：
  1. 自己用勺：允许吃得乱，鼓励自己舀。
  2. 脱鞋袜：配合脱鞋袜。
  3. 洗手：饭前洗手，边洗边玩水。
  4. 收玩具：玩完把玩具放回筐里。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：能不能独走几步？
  2. 观察：会不会蹲下站起、弯腰拾物？
  3. 观察：会不会说 3-10 个词？
  4. 观察：会不会用勺舀、叠积木、涂鸦？
  5. 提醒：走区软包、防磕碰，跑步要在看护下。

### 观察重点（五类，每类 5 条）
- 大运动：独走；走稳；蹲起；弯腰拾物；扶栏上台阶。
- 精细动作：舀倒；叠积木；翻页；涂鸦尝试；穿大珠。
- 语言：词量增加；两字词；听指令；指认五官；唱儿歌片段。
- 认知：颜色初识；大小比较；配对；物品用途；藏找。
- 生活技能：独立用勺；脱鞋袜；洗手；收玩具；表达意愿。

### 教具
- 家居：舀勺碗、叠杯、大画笔、纸、球、伞/盒、小推车。
- 食物类：安全蔬果（按医生建议允许时）。
- 低成本进阶：形状盒、配对卡（实物）、大块拼图、硬页绘本。
- DIY：舀豆盒（看护）、纸箱爬梯、感官瓶、涂鸦纸板。

### 空间与安全
- 走稳区软包、防磕碰；桌角防护；小物监管；家具固定；跑动路线无障碍。
- 安全清单：台阶护栏；柜门锁；剪刀类收高；电器收线；户外看护。

### 英文侧重
- 磨耳朵 + 动作词/名词 + 简短指令 TPR。
- 示例：`Let's walk!` / `Touch your toes.` / `This is a ball.`

### 主题适配
- 颜色、声音、身体、日常物品、自然、韵律、家务启发轮换；水果、动物开始加入。

## 段 6：19-24 个月（词汇爆发 · 跑跳期）

### 阶段特点
词汇爆发、可说短句；跑跳、分类、自理意识增强。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 穿大珠：连续穿 3-5 颗大珠。
  2. 叠高积木：叠到 4-6 块不倒。
  3. 拧瓶盖：拧开再拧紧瓶盖。
  4. 安全剪刀：在大人陪同下剪纸条。
  5. 涂色：在轮廓内涂大块颜色。
  6. 配对卡：把相同动物/颜色卡配对。
- 语言启蒙（每日抽 2-3）：
  1. 丰富词汇：每天命名 3-5 个新词（动物/水果/颜色）。
  2. 两三个词短句：说“妈妈抱”“球球给我”。
  3. 唱简单儿歌：完整唱 1 首短儿歌。
  4. 回答简单问题：问“这是什么”“要不要”。
  5. 描述物品：说“红色球、大狗狗”。
  6. 故事回应：听绘本时指认角色。
- 认知启蒙（每日抽 2-3）：
  1. 颜色/形状分类：把红球放红筐。
  2. 动物/水果命名：指图或实物说名字。
  3. 大小分类：把大、小球分开。
  4. 简单逻辑：完成 2 步指令（拿球再给妈妈）。
  5. 记忆配对：翻卡片找相同图。
  6. 日常规则：玩完收起来、吃饭坐好。
- 大运动 + 感统（每日抽 3）：
  1. 跑：在开阔软区轻跑。
  2. 跳离地尝试：双脚轻轻离地跳。
  3. 上楼梯（扶）：扶栏上下楼梯。
  4. 抛接球：接住抛来的大软球。
  5. 低平衡：走矮平衡木或垫子边缘。
  6. 推拉重物：推椅子/小车。
- 生活技能（融入每日）：
  1. 独立吃饭：用勺舀、用杯喝。
  2. 穿脱部分衣服：配合穿脱外衣、鞋。
  3. 如厕意识：有便意时提示大人。
  4. 收玩具：玩完分类放回。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：词汇是否明显增多、会说短句？
  2. 观察：会不会跑、跳尝试、扶楼梯？
  3. 观察：会不会分类、配对、命名动物水果？
  4. 提醒：蹦跳区放软垫，防摔伤。
  5. 提醒：剪刀、小物用后收回。

### 观察重点（五类，每类 5 条）
- 大运动：跑；跳离地尝试；扶楼梯；抛接球；低平衡。
- 精细动作：穿珠；叠高；拧盖；剪纸；涂色。
- 语言：词汇爆发；两三个词短句；唱儿歌；答问；描述。
- 认知：颜色/形状分类；动物水果命名；逻辑两步指令；记忆配对。
- 生活技能：独立吃饭；穿衣配合；如厕意识；收玩具。

### 教具
- 家居：大珠、积木、安全剪刀、配对卡、球、小台阶、绘本。
- 食物类：安全蔬果（允许时）、摆餐具。
- 低成本进阶：形状分类盒、大块拼图、画纸彩笔、多米诺。
- DIY：分类盒、感官米盒（看护）、纸箱平衡桥、情景卡片。

### 空间与安全
- 蹦跳区软垫；家具固定；防磕碰；小物监管；户外看护。
- 安全清单：剪刀/刀具收高；插座保护；阳台护栏；跑跳区无障碍；防跌倒。

### 英文侧重
- 磨耳朵 + 名词指认（颜色/动物）+ 短句 + TPR。
- 示例：`What color is this?` / `It's a cat.` / `Jump, jump!`

### 主题适配
- 颜色、动物、水果、声音、身体、日常物品、自然、家务、亲子轮换。

## 段 7：25-30 个月（模仿 · 自理 · 社交期）

### 阶段特点
句子更完整，剪刀与平衡能力提升，自理和社交明显。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 沿直线剪：沿纸条直线剪开。
  2. 画圆/直线：用画笔描圆和直线。
  3. 穿珠：穿更小孔径的珠子。
  4. 搭积木：搭出简单结构（房子/桥）。
  5. 大块拼图：完成 4-6 片拼图。
  6. 捏夹：用衣夹夹纸片。
- 语言启蒙（每日抽 2-3）：
  1. 完整短句：说 3-5 个字完整句。
  2. 提问：主动问“这是什么”“去哪”。
  3. 描述：描述看到的东西（“红色的花”）。
  4. 听故事回应：听完回答“谁”“在干嘛”。
  5. 唱整首儿歌：完整唱 1-2 首。
  6. 角色扮演：扮演妈妈/宝宝对话。
- 认知启蒙（每日抽 2-3）：
  1. 颜色/形状/大小/多少：比大小、数多少。
  2. 排序：把玩具按大小顺序排。
  3. 分类：按用途/颜色/形状分类归位。
  4. 记忆游戏：记住 3-4 个位置找物。
  5. 遵守规则：轮流、排队、游戏规则。
- 大运动 + 感统（每日抽 3）：
  1. 单脚平衡尝试：扶墙单脚站立片刻。
  2. 跳远：从矮台阶轻轻跳下。
  3. 接球：双手接住抛来的球。
  4. 攀爬小器械：安全矮滑梯/爬架。
  5. 骑小三轮车：试踩脚踏。
  6. 走平衡：走宽平衡木。
- 生活技能（融入每日）：
  1. 独立穿衣：穿脱外衣、鞋袜。
  2. 如厕训练：定时如厕，逐步自主。
  3. 洗手刷牙：饭前便后洗手、早晚刷牙。
  4. 帮忙家务：递抹布、收碗筷、浇花。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：会不会说完整短句、主动提问？
  2. 观察：平衡、跳、接球、攀爬能力如何？
  3. 观察：剪刀、拼图、穿珠是否进步？
  4. 观察：是否能独立穿衣、如厕、刷牙？
  5. 提醒：攀爬器械防摔，剪刀全程监督。

### 观察重点（五类，每类 5 条）
- 大运动：单脚平衡尝试；跳远；接球；攀爬；骑小三轮。
- 精细动作：沿直线剪；画圆线；穿珠；搭结构；拼图。
- 语言：完整短句；提问；描述；听故事回应；唱整首儿歌。
- 认知：排序；分类；多少大小；记忆游戏；遵守规则。
- 生活技能：独立穿衣；如厕；洗手刷牙；帮忙家务；情绪表达。

### 教具
- 家居：安全剪刀、拼图、穿珠、积木、三轮车、绘本、衣夹。
- 食物类：安全蔬果（允许时）、摆餐具、搅拌小任务。
- 低成本进阶：分类盒、蜡笔、大块乐高类、多米诺、贴纸书。
- DIY：创意画、家务小帮手、情景角色扮演、感官大米盆（看护）。

### 空间与安全
- 运动器械防摔；家具固定；户外看护；剪刀监督；小物用后收纳。
- 安全清单：器械定期检查；滑梯底铺软垫；车轮制动；攀爬上限；防夹手。

### 英文侧重
- 磨耳朵 + 简单对话 + 歌谣动作 + TPR。
- 示例：`Can you find the red one?` / `Let's sing together!` / `Good job!`

### 主题适配
- 动物、水果、颜色、身体、日常物品、自然、家务、韵律；加入简单角色扮演。

## 段 8：31-36 个月（入园准备 · 语言成熟期）

### 阶段特点
叙事与问题逻辑增强，自理独立，为入园做社交与习惯准备。

### 每日五大模块
- 精细动作（每日抽 3）：
  1. 精细剪刀：沿曲线剪。
  2. 握笔描画：画圆形、方形并涂色。
  3. 系扣/拉链尝试：扣大扣、拉拉链。
  4. 较复杂拼图：完成 8-12 片拼图。
  5. 建构游戏：用积木搭高塔、桥、车。
  6. 串珠排序：按颜色/形状规律串珠。
- 语言启蒙（每日抽 2-3）：
  1. 复杂叙述：讲今天做了什么、看/玩了什么。
  2. 问句理解：回答“为什么”“怎么办”。
  3. 时间概念：理解“今天、明天、白天、晚上”。
  4. 社交语言：打招呼、请求、谢谢、再见。
  5. 角色扮演：扮演医生/老师/妈妈对话。
  6. 听故事复述：听短故事后简答或复述片段。
- 认知启蒙（每日抽 2-3）：
  1. 数数概念：数 1-10 个实物。
  2. 大小/多少/长短：比较并说出。
  3. 分类归位：把玩具、衣物按类归位。
  4. 逻辑推理：完成简单多步指令、找规律。
  5. 记忆游戏：翻牌找相同、记住序列。
- 大运动 + 感统（每日抽 3）：
  1. 骑三轮车：独立踩踏前进。
  2. 单脚跳：单脚轻跳 1-3 次。
  3. 平衡控制：走平衡木、单脚站。
  4. 投掷：把球投进筐/圈。
  5. 球类：拍球、接球、踢球。
  6. 攀爬：安全爬架、滑梯。
- 生活技能（融入每日）：
  1. 独立如厕：主动如厕、擦净洗手。
  2. 穿衣穿鞋：独立穿脱外衣、鞋袜。
  3. 进餐收拾：用勺筷吃饭、餐后收碗。
  4. 整理书包/玩具：上学物品按序放。
  5. 情绪表达：用语言说“生气、开心、害怕”。
- 发育观察与提醒（每日抽 2-3）：
  1. 观察：会不会完整叙述、回答为什么？
  2. 观察：数概念、分类、记忆游戏如何？
  3. 观察：骑三轮、单脚跳、投掷是否进步？
  4. 观察：独立如厕、穿衣、吃饭、整理如何？
  5. 提醒：户外骑行戴头盔、远离道路。
  6. 提醒：入园前练习表达需求与轮流等待。

### 观察重点（五类，每类 5 条）
- 大运动：骑三轮车；单脚跳；平衡；投掷；攀爬。
- 精细动作：精细剪刀；握笔描画；系扣拉链；拼图；建构。
- 语言：复杂叙述；问句理解；时间概念；社交语言；故事复述。
- 认知：数概念；大小多少长短；分类归位；逻辑推理；记忆游戏。
- 生活技能：独立如厕；穿衣；进餐；整理；情绪表达。

### 教具
- 家居：拼图、建构、画笔、绘本、三轮车、安全剪刀、圆头训练筷。
- 食物类：安全蔬果（允许时）、参与简单备餐（看护）。
- 低成本进阶：多米诺、串珠、涂色本、排序卡、情景道具。
- DIY：角色扮演道具、家务小任务、创意美术、手偶故事。

### 空间与安全
- 户外安全、器械监督、道路安全；养成收纳与安全习惯。
- 安全清单：骑行戴头盔；远离马路；器械检查；小药箱放高；紧急电话认知（大人口述）。

### 英文侧重
- 磨耳朵 + 简短对话 + 歌谣 + TPR + 绘本听读。
- 示例：`What do you see?` / `Let's count.` / `Clean up time!`

### 主题适配
- 动物、水果、颜色、身体、日常物品、自然、家务、韵律；加入情景游戏与简单规则。
